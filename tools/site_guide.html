Browse saved results, or run a supported local case

The public website shows precomputed results. New calculations run on your computer, not in this website.

Choose the route you need

  • Browse saved results. Prerequisite: none. Outcome: saved campaign plots and downloads. Open the current 1M campaign. Other saved views: earlier results and teaching example or detector geometries.
  • Run the prepared-computer mouse example. Prerequisite: checked private AK02/SAP22 Cs137 deposits and field caches, Windows Python and pinned Julia. Outcome: bounded Cs137 native charge and readout from saved deposits. Open the mouse-interface instructions.
  • Prepare a generic new run. Prerequisite: full Windows/WSL setup and pinned upstream cryostat inputs. Outcome: setup checks and supported AK02/SAP22 selection for a new LBNL Cs137 radiation → charge → electronics case. Start the setup checklist, then select AK02 or SAP22.
  • Replay electronics from compatible saved charge. Prerequisite: a complete local signed-charge run, Windows Python and pinned Julia. Outcome: an electronics-only derivative, with no new radiation or SSD charge. Open saved-charge replay.
  • Use the advanced native CLI. Prerequisite: checked private AK02/SAP22 transport contracts and field caches, Windows Python and pinned Julia. Outcome: bounded new native charge and readout from saved deposits, with electronics-group checkpoints. Open native-readout commands.
  • Check or prepare a public source configuration. Prerequisite: existing Python 3.10+ for the public check; native preparation also needs checked originals, a Geant4 exporter and locked Linux environment. Outcome: a configuration check or geometry/source-macro preparation, without particle, SSD or electronics execution. Open source check and preparation.

Utilities: use status/inspection and generic resume for generic runs, or metadata-only recovery for an interrupted parent update. Replay and native-readout have their own resume commands.

Mouse, saved-charge and native CLI routes require compatible local inputs; a fresh checkout does not supply them. Seventeen viewable models do not imply seventeen executable adapters. The public website never starts calculations.

Explore all 17 detector geometries

Open the detector library, select a model and enable drag rotation. Each model has a geometry viewer, saved gallery and technical page. GeGI retains all 34 contacts and its saved multichannel signal explorer.

Geometry viewers support rotation, zoom, individual layer visibility and selected-contact isolation. Fields and drift movies in the galleries remain saved views, not interactive field solvers. Contact colors indicate IDs or labelled channel families, not doping or layer thickness.

Use GitHub Pages or a local HTTP server for JSON-fetching viewers. Opening HTML directly through file:// may retain only the static geometry fallback. A simple local server is python -m http.server 8765 --bind 127.0.0.1 --directory docs.

1. Windows setup checklist

This full checklist prepares a generic new LBNL run. For compatible saved inputs, follow the separate replay or native-readout prerequisites.

Use PowerShell in the repository root (the folder containing Run.cmd). Prepare the steps in order. These are explicit installation/acquisition actions; browsing the website and running .\Run.cmd check do not perform them for you.

Obtain a checkout first

Install Git, then open PowerShell in the folder where you want this project. A source-only checkout is sufficient for calculation; browse the saved results online.

git clone --filter=blob:none --sparse https://github.com/Kunming-CN/END2END_Ge_Simulation.git
cd END2END_Ge_Simulation
git sparse-checkout set models simulation transport scenarios tools

The current directory now contains Run.cmd. For an offline copy of the saved website/media, also run git sparse-checkout add docs; a full clone is another option. Neither clone command installs physics dependencies.

A. Install the platform prerequisites

Install Git and Juliaup, enable WSL2 with the Ubuntu-24.04 distribution, and install Pixi inside Ubuntu. Use the Juliaup installer instructions, Microsoft WSL instructions and Pixi installer instructions. WSL installation may require an administrator and restart. No GPU is required. For the optional local workspace index and local HTTP browsing, install Windows Python 3.10+; those utilities need only its standard library. ParaView is not a student runtime prerequisite.

B. Select the exact reviewed Julia version and instantiate SSD

juliaup add 1.13.0
juliaup override set 1.13.0
julia --version
julia --startup-file=no --project=simulation -e "using Pkg; Pkg.instantiate()"

The directory override selects Julia 1.13.0 for this checkout without changing other projects' default. The LBNL preflight also checks SSD 0.11.8, JSON 1.9.0 and Unitful 1.29.0 from the supplied environment. Keep its Project/Manifest pair unchanged.

C. Install the locked Linux transport environment

$Project = (Get-Location).Path
wsl.exe -d Ubuntu-24.04 --cd "$Project\transport" -- bash -lc '$HOME/.pixi/bin/pixi install --locked'
.\transport\Run.cmd versions

The version check should report remage 1.1.0 and Geant4 11.3.2. The large dependency environment belongs in Pixi's Linux cache, not in the synced source tree. Later version checks use --no-install; they fail rather than silently installing a missing environment.

D. Obtain the pinned upstream cryostat files

The nine upstream files are not redistributed here. The following PowerShell recipe reads their pinned repository, commit, path and hashes from transport/cryostat-source.json. It preserves matching existing files and stops on a mismatch. A failed download remains a labelled .download file for inspection.

$m = Get-Content .\transport\cryostat-source.json -Raw | ConvertFrom-Json
$target = Join-Path (Get-Location).Path $m.local_cache
New-Item -ItemType Directory -Force $target | Out-Null
foreach ($f in $m.files) {
    $dest = Join-Path $target $f.name
    if (Test-Path -LiteralPath $dest) {
        if ((Get-FileHash -LiteralPath $dest).Hash.ToLowerInvariant() -ne $f.sha256) { throw "Existing file differs: $($f.name)" }
        continue
    }
    $temp = $dest + '.download'
    if (Test-Path -LiteralPath $temp) { throw "Inspect previous download first: $temp" }
    $url = 'https://raw.githubusercontent.com/' + $m.repository + '/' + $m.commit + '/' + $m.directory + '/' + $f.name
    Invoke-WebRequest -UseBasicParsing -Uri $url -OutFile $temp
    if ((Get-Item -LiteralPath $temp).Length -ne $f.bytes -or (Get-FileHash -LiteralPath $temp).Hash.ToLowerInvariant() -ne $f.sha256) { throw "Downloaded bytes differ: $($f.name)" }
    [IO.File]::Move($temp, $dest)
}

The result is .local/transport/LBNL/ containing the exact manifest-listed files, not another level of nested repository folders. This uses upstream bytes locally; it does not relicense or publish them.

E. Check, build the exporter, then check again

.\Run.cmd check
.\Run.cmd setup -BuildExporter
.\Run.cmd check

Before the exporter is built, check may correctly return exit 2. After all prerequisites and the build succeed, it should return exit 0 with ready : True. A missing-dependency failure is not installation success. Stop and address the reported item rather than starting a run.

This ordered recipe follows the current preflight predicates. Fresh-machine installation remains unvalidated; the recorded clone test checked correct rejection of missing prerequisites. One custom AK02 500-decay uninstrumented run is recorded on the existing computer; broader positive replacement acceptance is still unvalidated. See validation scope.

2. Start a generic new LBNL run

.\Run.cmd detectors
.\Run.cmd run -Detector AK02 -Preset demo
.\Run.cmd run -Detector SAP22 -Preset demo

The double-click Run.cmd menu offers the same selection without editing YAML. Choose one command/model for a new run; use -Detector both to run two separate cases serially, not two crystals together.

All 17 geometries are viewable, but the nominal LBNL Cs137 end-to-end adapter currently implements AK02 and SAP22 only. Additional models require geometry/placement and readout checks; a model must never be scaled to fit. Scenario and assumptions.

The demo preset uses 500 initial decays per selected detector. Smoke uses 20 and may produce no Ge pulse. The 10k preset requires a verified 500-event pilot. Million-event production is not a beginner default.

The selected case proceeds through radiation deposition, native SSD charge transport, synthetic preamplifier/shaping and peak ADC. Geant4 deposition times are not carrier drift times; deposited and reconstructed energies remain separate quantities.

Local mouse interface: bounded native example

Double-click Control.cmd in the project root. It opens a session-protected page on 127.0.0.1 using an existing Python 3.10+ (the current SITE_PYTHON, otherwise installed ParaView 6.1.1, otherwise an existing PATH Python). Nothing is installed and system PATH is unchanged. The checked private inputs and pinned Julia environment described below are required; a fresh clone is not a runnable substitute.

Select AK02 (default IDs 0,2594,3950) or SAP22 (IDs 0,207,263), choose an unused result name, click Check inputs, then explicitly Run. Each example retains three complete primaries, including one true zero, and fixed recorded physics/electronics settings. The interface calls the same backend as Run.cmd native-readout; it does not calculate new radiation or fields. Its child process uses existing Windows PowerShell built-in modules and the existing pinned Julia 1.13.0 binary, avoiding incompatible inherited modules or unreadable WindowsApps aliases. An explicit JULIA_EXE is honored exactly; an invalid explicit path refuses rather than falling back. Runtime versions and bytes are still independently checked by the backend.

Stop waits for the current verified step. The first step finishes all missing native charge, independent calibration and one electronics group; it is not an immediate per-particle interruption. Continue uses only saved selectors/configuration. A finished last step stays completed even if a late stop request arrives. Reopening the browser attaches to the same job and never starts a new calculation. Saved-result verification/continuation also requires the same Python executable recorded in that run; a different default interpreter is refused without rebasing provenance. Launch with the matching existing SITE_PYTHON when needed. Stop the job before closing the interface terminal; a restarted interface checks existing process/lease records before permitting work.

Progress, logs and exact-byte result/settings/receipt downloads are available locally under .local/native-readout-integration-v1/implementation/outputs/NAME. Control metadata stays under .local/local-control-v1/. This low-statistics noiseless engineering route is not calibrated CCE, experimental-spectrum or newcomer acceptance. Arbitrary models, source/geometry editing, new radiation and electronics editing are not exposed by this first interface.

Save electronics settings

.\Run.cmd settings
.\Run.cmd settings show -View advanced
.\Run.cmd settings save -SaveName my-electronics
.\Run.cmd settings check -SettingsFile .local/electronics-profiles/my-electronics.json
.\Run.cmd run -Name my-custom-smoke -Preset smoke -Detector AK02 -ElectronicsProfile .local/electronics-profiles/my-electronics.json

Simple editing exposes shaping time, gain, threshold and peak ADC bits/range; advanced also exposes capacitance, decay, pole-zero compensation, peak policy and optional gates with units. The exact default shaping time is 0.5 microseconds. Saves retain all settings and input/source provenance; existing saves are never overwritten. Show, check and compare read files only.

Saved custom electronics are implemented for NEW AK02/SAP22 runs. A custom run performs normal upstream calculation; it does not automatically reuse old charge or fields. The larger preset requires a verified 500/model pilot with matching effective electronics and compute dependencies. Resume and inspection use the recorded copied binding, and resume rejects configuration overrides. Settings show/check/compare remain read-only configuration checks; execution additionally checks numerical sample/window feasibility. The separate saved-charge replay route is implemented for compatible existing inputs. The analog numerical grid is not waveform ADC sampling; gates use each readout trace/Cs137 pulse-group origin. See exact syntax, binding, evidence scope and reuse limits.

Advanced: replay electronics from saved charge

Requires PowerShell at the repository root, installed Windows Python 3.10+, Julia 1.13.0 / JSON 1.9.0 in the unchanged simulation project, and a compatible complete source under .local/runs/SOURCE. The source must contain full signed signals.csv, identities, timing, flags and matching producer/input bindings. Public report HTML, display-decimated traces and model ZIPs are not replay inputs. This entry does not load SSD/native transport or invoke Geant4.

.\Run.cmd replay-readout -Name SOURCE -ReplayName NEW -Detector AK02 -CheckpointGroups -DryRun -Json
.\Run.cmd replay-readout -Name SOURCE -ReplayName NEW -Detector AK02 -CheckpointGroups -Json

Replace SOURCE with the compatible source run and NEW with an unused derivative name. Output lives under .local/replays/NEW. Omitting an electronics profile retains the recorded configuration; a new derivative may explicitly select -ElectronicsProfile. Each effective configuration uses a separate fixed synthetic-injection calibration, never per-event truth-energy gain.

.\Run.cmd replay-readout -Name SOURCE -ReplayName NEW -Detector AK02 -CheckpointGroups -Resume -DryRun -Json
.\Run.cmd replay-readout -Name SOURCE -ReplayName NEW -Detector AK02 -CheckpointGroups -Resume -Json

Keep the same source, derivative name and detector selection on replay resume. Profile overrides refuse on resume. Optional -StopAfterGroups 1 stops at a verified new group commit; it requires -CheckpointGroups. The default one-shot replay remains available without that flag, but has no group recovery. Read-only dry-runs do not verify the loaded runtime. See charge/replay contracts and checkpoint limits.

Advanced: bounded new native charge → readout

Requires PowerShell at the repository root, installed Windows Python 3.10+, the pinned Julia 1.13.0/SSD simulation environment, and the existing checked private cs137-1m transport contracts, prepared geometry and native field caches. These inputs are not in a fresh checkout or the model download. This entry generates new charge from recorded deposits, then independent fixed-injection calibration and synthetic electronics; it performs no radiation or field rerun and accepts no arbitrary input/cache import.

This entry uses the existing executable selected by SITE_PYTHON; otherwise it uses %ProgramFiles%/ParaView 6.1.1/bin/pvpython.exe. It does not find standalone Python through PATH. To select an already installed standalone interpreter, replace the illustrative path below with its actual executable path and set it in the current PowerShell session. This does not install Python or change system PATH.

$env:SITE_PYTHON = 'C:\path\to\installed\python.exe'
.\Run.cmd native-readout -Name native-example -Detector SAP22 -DryRun
.\Run.cmd native-readout -Name native-example -Detector SAP22 -StopAfterGroups 1
.\Run.cmd native-readout -Name native-example -Resume -DryRun
.\Run.cmd native-readout -Name native-example -Resume

A new SAP22 command defaults to original IDs 0,207,263; omitting Detector selects the original AK02 cohort. Each command handles one checked detector; both and other models refuse. Optional quoted -PrimaryIds selects whole original primaries within 8 primaries, 4 groups and 100 complete raw rows. Zeros, deposition clocks, seeds and endpoint flags remain recorded. Existing nominal caches use an explicit 77 K override from the original 78 K models. Original detector biases are +500 V for AK02 and +700 V for SAP22, applied to contact 2; contact 1 is the 0 V readout electrode for both.

Output lives under .local/native-readout-integration-v1/implementation/outputs/NAME. Use an unused name of at most 24 letters/digits/underscores/hyphens. Native resume obtains detector and IDs from the witnessed manifest: omit all Detector/PrimaryIds selectors, even matching values. StopAfterGroups counts newly committed electronics groups after native charge has completed; it is not an immediate native stop. Source/runtime/model/cache mismatches refuse. Preserve prior outputs and receipts; do not rehash them to bypass a refusal. See exact bounded contract and acceptance.

Advanced: check a supported source configuration

The opt-in preparation adapter selects the existing nominal LBNL cryostat, AK02 or SAP22, a Cs137 point decay or a synthetic 662 keV gamma along global -y, and a centered nominal or +5 mm source pose. From the project root, an existing Python 3.10+ can check the public configuration without physics packages or private inputs:

python transport/scenario_prepare.py check --config scenarios/m11a-ak02-mono_gamma_662_axis_v1-plus5mm.json

Native preparation additionally requires the checked upstream originals, existing Geant4 exporter and locked Linux environment. It checks geometry and writes a source macro in a new local output root; it does not run the planned particles, SSD or electronics. Each new preparation needs native containment/overlap and mapping checks. The nominal geometry is not an experimental survey, and a prepared input is not a completed end-to-end source run. See the finite preparation contract, explicit launcher syntax and limitations. This entry is separate from the local mouse interface.

3. Inspect status, open results or resume conservatively

.\Run.cmd status
.\Run.cmd inspect -Name RUN_NAME
.\Run.cmd open -Name RUN_NAME

inspect reads saved files without importing Julia, invoking WSL, creating a lock or writing results. Exit 0 means terminal saved-state checks passed; exit 2 reports blockers. It does not establish runtime readiness or permission to execute. Add -Json for one machine-readable object.

A source mismatch can legitimately block reuse of an old completed campaign. It does not require rerunning it or editing its receipts. open may regenerate the local presentation index; inspect does not.

.\Run.cmd resume -Name RUN_NAME -DryRun
.\Run.cmd resume -Name RUN_NAME

The resume dry-run performs saved-state inspection only. Actual resume remains a separate explicit action and rechecks inputs under its own lock.

Use the run name printed by the launcher. Results and receipts live under .local/runs/RUN_NAME. Open and status do not start a calculation. Resume verifies saved inputs/settings and complete-stage outputs before reuse.

An incomplete transport, stream or native stage is preserved for inspection. Generic run/resume does not provide per-group recovery inside an interrupted native stage. The separate bounded native-readout entry has verified group checkpoints. The completed production workflow must not be restarted merely to inspect its results.

Advanced: recover a completed child’s parent update

.\Run.cmd recover -Name RUN_NAME -DryRun -Json
.\Run.cmd recover -Name RUN_NAME -Json

This generic-run action reconciles a completed guarded native child when its parent metadata update was interrupted. It requires the existing compatible run, launch intent, receipts and lock. Dry-run inspects only; actual recovery writes an additive metadata transaction. Neither command starts missing calculations, calibrates, resumes groups or adopts partial/legacy responses. It is separate from replay and native-readout resume. See recovery boundaries.

What has actually been validated?

The completed 1M-per-detector campaign, native response and explicit failure accounting are saved engineering results. Synthetic electronics and numerical tests do not establish experimental energy resolution or calibrated charge-collection efficiency.

The earlier guarded regression passed 64 assertions using eight saved positive groups and test-only verified field-cache injection. Its source-only checkout test on the same computer correctly rejected missing prerequisites. Those historical checks alone do not validate positive uninstrumented orchestration, a new field solve or fresh-machine installation. Separately, one custom-profile AK02 500-decay uninstrumented run completed on the existing computer; this is one recorded configuration, not all-model or fresh-machine acceptance. Exact acceptance boundaries.

Saved-charge replay and bounded existing-input AK02/SAP22 native-readout have separate public-command and checkpoint-recovery acceptance on the existing host. These do not validate arbitrary inputs, calibrated physical charge collection, hardware or experimental agreement. Fresh-machine/no-code acceptance remains deferred to a second computer.

The original gallery uses synthetic deposits. Earlier 10k event viewers and 1M aggregate results are distinct datasets; links identify their campaign. Native failures are unknown responses, not zero-energy measurements.

Keep local files understandable

Open_Workspace.cmd refreshes a local-only dashboard grouping results, current runs, code/models, references and review evidence. It does not launch or resume simulations. Generated dashboards and private documents are not published.

Permanent transport archives, fields and native checkpoints remain at their existing paths. An unfamiliar folder under .local is not disposable cache. Use the workspace guide before reorganizing them.
